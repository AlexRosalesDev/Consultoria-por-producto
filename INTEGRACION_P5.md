# Día 1 – Integración (P5)

## Arquitectura del sistema

El sistema está compuesto por:

- Backend (Django): expone datos mediante API REST
- Frontend (Vite): consume los datos y los muestra

## Módulos:

- Mapa
- Gráficos
- Filtros

## Flujo de datos:

API → Frontend → Mapa + Gráficos

## Rol:

Encargado de integrar los módulos asegurando la comunicación entre backend y frontend.
